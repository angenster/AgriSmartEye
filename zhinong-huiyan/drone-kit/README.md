# 智农慧眼 - 植保无人机改装套件

## 套件概述

本套件用于将现有植保无人机升级为AI驱动的精准变量施药平台，集成多光谱成像、边缘AI推理和变量喷头控制。

## 硬件组成

### 核心组件

| 组件 | 型号 | 说明 |
|------|------|------|
| 边缘计算单元 | Jetson Nano 4GB | 实时AI推理 |
| 多光谱相机 | MicaSense RedEdge-P | 5波段多光谱成像 |
| 变量喷头控制器 | 定制PWM控制器 | 8路独立流量控制 |
| 流量传感器 | YF-S201 | 实时流量监测 |
| GPS/RTK模块 | u-blox ZED-F9P | 厘米级定位 |
| 4G通信模块 | Quectel EC25 | 云端数据回传 |
| 电源管理模块 | 定制DC-DC | 稳压供电 |

### 适配机型

- 大疆 T30/T40/T50
- 极飞 P100/V50
- 其他支持MAVLink协议的植保无人机

## 安装指南

### 1. 多光谱相机安装

```
安装位置：无人机腹部，镜头垂直向下
固定方式：碳纤维支架 + 减震垫
连接：USB 3.0 → Jetson Nano
供电：12V DC
```

### 2. 边缘计算单元安装

```
安装位置：无人机机身中部
散热：主动散热风扇 + 导热硅脂
防水：IP67防护外壳
连接：
  - USB → 多光谱相机
  - UART → 飞控MAVLink
  - PWM → 喷头控制器
  - 4G → 通信模块
```

### 3. 变量喷头改装

```
原喷头 → 流量传感器 → 电磁阀 → 雾化喷头
              │
              ▼
        PWM控制器 (Jetson GPIO)
```

每个喷头独立控制：
- 流量范围：0.5 - 5.0 L/min
- 响应时间：< 100ms
- 控制精度：±5%

### 变量施药算法

```python
def calculate_spray_rate(disease_severity, crop_density, wind_speed):
    """
    变量施药算法
    重病区多喷、轻病区少喷、未发病区不喷
    """
    base_rate = 2.5  # L/min

    # 病情权重
    severity_weight = {
        "healthy": 0.0,
        "mild": 0.5,
        "moderate": 1.0,
        "severe": 1.5,
    }

    # 作物密度权重
    density_weight = crop_density / 100.0

    # 风速修正
    wind_factor = max(0.5, 1.0 - wind_speed / 20.0)

    rate = base_rate * severity_weight[disease_severity] * density_weight * wind_factor
    return min(rate, 5.0)  # 最大5L/min
```

## 使用流程

### 1. 任务规划

```bash
# 上传田块边界
python mission_planning.py --field A-03 --boundary boundary.kml

# 生成航线
python generate_waypoints.py \
    --field A-03 \
    --overlap 30 \
    --altitude 3.0 \
    --speed 5.0
```

### 2. 起飞前检查

```bash
# 系统自检
python preflight_check.py

# 检查项：
# ✓ 电池电量 > 30%
# ✓ 喷头通畅
# ✓ 药液充足
# ✓ GPS信号良好
# ✓ 4G网络连接
```

### 3. 执行作业

```bash
# 启动自动作业
python start_mission.py --waypoints mission_A03.json

# 或手动控制
python manual_control.py
```

### 4. 数据回传

作业数据实时回传云端：
- GPS轨迹
- 施药量记录
- 多光谱图像
- AI识别结果

## 安全规范

### 飞行安全

- 飞行前检查气象条件（风速 < 10m/s）
- 保持与障碍物的安全距离（> 10m）
- 作业时设置安全警戒线
- 配备观察员监控飞行状态

### 施药安全

- 使用登记农药，遵守安全间隔期
- 佩戴防护装备
- 避开水源和居民区
- 关注天气，避免雨天作业

### 设备安全

- 定期检查喷头堵塞情况
- 清洁多光谱相机镜头
- 检查电源连接可靠性
- 更新边缘计算单元固件

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 喷头不出药 | 堵塞/电磁阀故障 | 清洗喷头/更换电磁阀 |
| 流量不准确 | 传感器漂移 | 重新校准 |
| 图像模糊 | 镜头脏污/震动 | 清洁镜头/加固支架 |
| 定位偏差 | GPS信号弱 | 检查天线/启用RTK |
| AI识别率低 | 模型过时 | 更新模型权重 |
