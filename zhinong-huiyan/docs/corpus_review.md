## 3. 校对流程（可签字、可追溯）

语料正文与校对状态分离：正文在 `seed_corpus.py`，签字记录在
`backend/rag/corpus_reviews.json`（由工具生成，不入库正文）。

```bash
cd zhinong-huiyan/backend

# 1) 导出待校对清单（Excel 可直接打开）
./.venv/Scripts/python.exe -m rag.review_corpus --export ../docs/corpus_review.csv

# 2) 植保人员逐条填写 reviewer / reviewed_at / verdict / notes
#    verdict 取值：通过 | 需修改   （留空 = 保持原状态）

# 3) 回填结论
./.venv/Scripts/python.exe -m rag.review_corpus --apply ../docs/corpus_review.csv

# 4) 重建索引，让 source / reviewed 状态生效
./.venv/Scripts/python.exe -m rag.indexer

# 随时查看进度
./.venv/Scripts/python.exe -m rag.review_corpus --status
```

规则：

- `verdict=通过` 必须填写 `reviewer`，否则不采纳；通过后该条目入库
  `source="manual_reviewed"`，`metadata` 带校对人与日期。
- `verdict=需修改` 会撤销已通过状态并保留修改意见，防止带病上线。
- 留空或“待定”不改变原状态，避免误撤销已有签字。
- 索引重建前，检索与报告里仍显示 `ai_draft_unreviewed`，前端会如实呈现。
