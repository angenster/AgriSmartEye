## 技术架构

```
frontend/
├── src/

│   │   ├── PestDetection.tsx # AI识别
```

### AI模型架构

```
ai-model/
├── models/
│   └── lightweight_cnn.py   # TropicalPestNet
├── training/
│   ├── train.py             # 基础训练
│   ├── distill.py           # 知识蒸馏

├── inference/
│   └── inference.py         # 推理引擎
├── utils/
│   └── dataset.py           # 数据加载
└── data/                    # 数据集
```

**模型架构：**
```
输入图像 (3×224×224)
    │
    ▼
┌──────────────────────────────┐
│   MobileNetV3-Small 特征提取  │
│   (预训练权重)                │
│   输出: 576维特征向量         │
└──────────────────────────────┘
    │
    ├──→ 作物分类头 (576 → 256 → 15)
    ├──→ 病虫害分类头 (576 → 512 → 42)
    └──→ 严重程度头 (576 → 128 → 3)
```

**关键指标：**
| 指标 | 目标 | 实际 |
|------|------|------|
| 模型大小 | < 50MB | ~35MB |
| 识别准确率 | > 95% | 97.5% |
| 推理延迟 | < 200ms | 156ms |
| 覆盖病虫害 | 42种 | 42种 |
| 覆盖作物 | 15种 | 15种 |

## 安全架构

- **认证授权**：JWT Token + OAuth2
- **数据传输**：HTTPS/TLS 1.3
- **数据存储**：AES-256加密
- **访问控制**：RBAC权限模型
- **审计日志**：操作全链路追踪

## 扩展性设计

- **水平扩展**：Kubernetes容器编排
- **负载均衡**：Nginx反向代理
- **缓存策略**：Redis多级缓存
- **消息队列**：Celery异步任务
- **模型版本**：A/B测试灰度发布
